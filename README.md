# LiveKit landscape

A map of LiveKit drawn from GitHub issues. Open [the site](https://emms21.github.io/livekit-landscape/) or `index.html` in a browser.

## Analytics

[Umami](https://cloud.umami.is) records visits on GitHub Pages. Local `localhost` is skipped.

Custom events: `place` (where you are), `ticket` (issue opened), `lab` (airplane-mode lab), `engaged` (stayed 20s or visited 3 places).

In Umami, the website domain must be `emms21.github.io` (hostname only, no path).
